Reference Architecture

Webhook → Process → Notify

The pattern I use for most business automations:

Trigger: Webhook node (POST) e.g. contact form submission Process: Code / OpenAI nodes parse, enrich, validate, transform Branch: IF node route by type, spam filter, priority Notify: Email / Slack / Sheets deliver the outcome Observe: n8n execution log error alerts + retry policy
